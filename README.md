# GrowOS

Your AI marketing system. Newsletters, social media, ads, landing pages, video editing, and more — in your voice, learning from every correction.

---

## Get Started

1. Open this folder in **Claude Desktop** (Code tab → Open folder) or run `claude` in your terminal
2. Say anything. The system will guide you through setup automatically.

That's it. Setup takes about 5 minutes. You'll answer a few multiple-choice questions while the system researches your business, learns your voice, and configures everything.

---

## After Setup

Type any command to start creating:

| I want to... | Type this |
|--------------|-----------|
| Write a newsletter | `/newsletter-write` |
| Plan social media | `/social-plan` |
| Write social posts | `/social-write` |
| Create a landing page | `/landing-page` |
| Write an article | `/article-write` |
| Create Facebook ads | `/ads-create-fb` |
| Research competitors | `/research-competitor` |
| Repurpose into many formats | `/repurpose` |
| Make it sound more human | `/humanize` |
| Check reading level | `/check-readability` |
| Build a custom workflow | `/skill-creator` |
| Update GrowOS | `/update` |

Or just describe what you need in plain language. The system will route you to the right workflow.

---

## Tips

**Multiple businesses?** Say "add new business" to set up another one. Say "switch to [name]" to change between them.

**Deepen your profile:** Say "go deeper" or "complete my profile" anytime to add more detail about your voice, audience, or competitors.

**Give feedback:** After any output, tell the system what you'd change. It saves your corrections as permanent rules and gets better every time.

**Integrations:** Check `system/config/integrations.md` for connecting email platforms, social scheduling, and more.

**Updates:** When you receive a new version, type `/update` and point it to the downloaded folder.

**Hidden folders:** GrowOS stores skills and rules in `.claude/` (hidden by default). Press `Cmd + Shift + .` on Mac or enable "Show hidden items" on Windows to reveal it. You don't need to see it — Claude handles it automatically.
